# Calculadora Tkinter

Aplicación de escritorio con interfaz gráfica moderna en tema oscuro desarrollada en Python usando `tkinter`.

## Características
- Entrada para dos operandos numéricos.
- Desplegable con operaciones aritméticas: **Sumar**, **Restar**, **Multiplicar** y **Dividir**.
- Botones de acción: **Calcular** y **Limpiar**.
- Validación de entradas y control de división entre cero.
- Diseño oscuro moderno inspirado en paleta navy / turquesa mint.

## Requisitos
- Python 3.x (`tkinter` viene incluido en la instalación estándar de Python en Windows/macOS).

## Ejecución
```bash
python calculadora.py
```
